本Lab要求针对一道PA题给出的十份错误代码，分析出错原因以及可能发生的最严重错误，并给出一个能够造成最严重错误的测例。


## code 1 {#code-1}


1. 最严重错误类型：Runtime Error

2. 产生错误原因：在`play()`函数中，由于游戏可能消除到rank=0的位置，此时会递归调用`play(-1)`，从而出现越界访问`a(-1)`的情况，造成Runtime Error。

3. 测例构造：构造一个会向前消除到rank=0位置的测例即可触发此错误。测例如下：

    ```cpp
    AAB
    1
    0 A
    ```

## code 4 {#code-4}


1. 最严重错误类型：Wrong Answer

2. 产生错误原因：在`play()`函数中，`left`的起始位置为rank，判断能否消除是根据`right - left >= 3`来判断，则应在`while (left > 0 && a.at(left) == color) --left;`语句后增加一句`left += 1;`来确保检查完毕后left在正确的可消除区域的左端点，而本程序中没有这一句，则会导致错误的区域消除，从而造成Wrong Answer。

3. 测例构造：构造测例使得插入的字符恰好与该位置右侧的字符相同，则会导致错误的消除。测例如下：

    ```cpp
    ABC
    1
    1 B
    ```




## code 5 {#code-5}


## code 7 {#code-7}


1. 最严重错误类型：Wrong Answer

2. 产生错误原因：在消除的时候可能会出现中间某一块长度为0的情况，设这一块为第$i$块，此时若第$i-1$块的末尾与第$i+1$块的开头可以进行消除，但执行消除过程的时候左端点一次只能移动一块，这会导致`l.second < 0`，从而导致无法执行这样的消除操作。

3. 测例构造：构造测例使得中间某块可以被消除至长度为0，且前后可以形成可消除块即可。测例如下：

    ```cpp
    1025
    2048 B
    2048 C
    2048 B
    2048 C

    2048 B
    2048 C
    2048 B
    ```

## code 9 {#code-9}


1. 最严重错误类型：Runtime Error

2. 产生错误原因：没有考虑到在同一块字符内出现消除的情况，此时会导致`len < 0`，而数组`plen`中存储的数据类型为`unsigned long long`，此时会导致某一块长度超过最大长度，从而导致溢出，造成Runtime Error。

3. 测例构造：构造在某一块内产生消除的情况即可，例如在第一块消除，测例如下：

    ```cpp
    ABBC
    1
    1 B
    ```




## code 10 {#code-10}
